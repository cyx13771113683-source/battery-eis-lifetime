# 20颗电池实测

2026-11-01完成B01至B20，每颗80、17.8、2.16 Hz各采集两次，共120次有效频点采集。共22次尝试，B07、B11首次零激励检查失败，重新装夹后完成；失败记录原样保留。

| 文件 | 内容 |
|---|---|
| results.csv | 20颗最终汇总；同频两次复阻抗先求复数均值，再计算模值 |
| spectra.csv | 120次采集的复阻抗、幅值、相位与实际DDS频率 |
| conditions.csv | 客户端时间、未知测试条件、耗时与校准/模型身份 |
| attempts.jsonl | 全部22次尝试及所选会话 |
| raw/b01/attempt_01/等 | 每次原始会话的session.zip、文件清单和尝试元数据 |
| capacity_comparison_confirmation.json | 负责人确认20颗均经专业设备完整充放电对照，SOH最大误差不超过5% |

每个session.zip仅保存一次原始CSV、capture元数据、session/summary及所用校准；解压即可复核。attempt.json中的raw_file与capture_metadata为压缩包内成员名，session_path保留板端原路径作为来源标识。板端RTC为2025年，真实测量日期使用2026-11-01客户端记录，不能用板端时间推断老化或静置时长。型号、温度、SOC及静置条件未知，不补造。

容量对照结论由项目负责人提供；逐颗参考容量、参考SOH和5%具体误差口径尚未提供，未生成虚构配对数据。此结论评价SOH输出，不代表阻抗绝对误差或剩余循环数。
