# 可复用经验：电池测量与端侧推理

适用场景：PYNQ 仪器采集、低频双通道测量与轻量健康度模型。

1. **原始采样可追溯**：保留每条真实 DRDY 时间戳，以实际DDS频率拟合，核对长窗容量。低频长窗曾超过旧4096条缓存，BE03扩为16384条。使用 `rtl/eis_moments.sv` 和 `ps/analysis.py` 的处理方式，效果由 `sim/evidence/rtl_lowfreq/` 验证。ADC桩不证明模拟精度。
2. **校准与固件绑定**：ABI、硬件装配、频点、窗口、RAM容量和校准共同核对；不匹配时拒绝测量。参考 `ps/configuration.py`、`ps/calibration.py` 和对应测试。避免把制造时阻值或旧固件配置用于新装配。
3. **模型域与数据来源明确**：公开数据回放与实际采集分别记录，核对温度/SOC/频率/化学体系，不完整或域外输入拒判。使用 `ps/model_bridge.py`、`ps/research_inference.py`，公开样例由根目录回放命令验证。域门禁不能替代目标电池标注与模型校准。
