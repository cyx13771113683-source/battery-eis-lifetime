# 可复用经验：PYNQ电池测量与端侧推理

适用于PYNQ仪器、自启界面、低频双通道锁相测量与轻量模型。以下规则来自本项目实际故障与验证；可迁移机制，管脚、地址、门限和校准不可照抄。

| 触发故障/观察 | 使用方式 | 已验证效果与边界 |
|---|---|---|
| 低频长窗超过旧4096条缓存 | 保留真实DRDY时间戳；BE03扩为16384条；按实际DDS频率拟合 | `sim/evidence/rtl_lowfreq/`验证容量/矩累积，ADC桩不证明模拟精度 |
| 校准、装配或固件版本不匹配 | 同时绑定ABI、BIT/HWH、装配哈希、频点和窗口，再执行模型 | `tests/test_program_review.py`覆盖不匹配拒绝；实际模拟精度仍需标准件 |
| 零激励存在表观毫安读数 | 先验证零输出和电气状态，再有界估计直流零偏，同时核对噪声、漂移和过流原始值 | `tests/test_current_zero.py`及相关测试；不以减常数代替交流传递校准，不解除过流保护 |
| 重启仍显示旧测量记录，且RTC不可靠 | 程序启动时快照旧会话目录，显示端只接纳新会话；不删除原始文件 | 149项测试含时钟回退/旧未完成会话；实板重启列表0条，905个文件保留 |
| 多次启动日志混在一起 | 当前运行日志用覆盖方式创建，journal按InvocationID查询 | v6真实重启日志仅本次启动；保留系统历史证据 |
| 测寿命打断单点后未恢复 | 保存频率及运行状态；旧作业退出并停止输出后启动扫频，正常完成后恢复 | `tests/test_live_control.py`回放80Hz恢复；取消/故障保持停止 |

## 复用步骤

先运行仓库README的离线测试和回放，再按`board/README.md`准备运行目录。首次接入目标板时核对实际模块、接线与校准；启动验收同时检查服务当前InvocationID、首帧和零激励状态。生成SOH需要本轮完整频谱，显示缓存不可补齐模型输入。规则失效时保存原始数据和失败阶段，再定位原因。
