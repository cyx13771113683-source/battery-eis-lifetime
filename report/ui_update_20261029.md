# 电池操作界面更新 · 2026-10-29

首页、设置、记录三页沿用既定布局。设置页仅提供连续单点和频点选择；单点不会触发寿命分析。首页“寿命测量”固定使用80、17.8、2.16Hz，暂停单点后等待旧任务退出，再开始整组采集。正常完成后恢复原来的单点频率与运行状态；原先未运行则保持停止。取消或故障时停止输出。

幅值、相位曲线按三个频点各保留最新数据，某个频点更新时其他点保持显示；重启可从显示缓存和既有完成记录恢复曲线。缓存只用于显示，SOH仍使用本次整组采集的数据。没有测量值的频点不补造数值。

记录页仅显示模型允许展示、数值有限且在0–100%范围内的SOH结果，总条数、分页和序号均按过滤后的记录计算。无SOH、损坏或读取失败的记录不出现在操作列表；原始文件和底层诊断索引保留。详情页只保留返回、SOH和两张曲线。

界面字库加载后复用，静止画面不重复绘制；单点按钮扩大有效点击区域。保持触摸坐标映射、测量算法、模型、校准参数、保护门限和BE03位流不变。

本次验证使用仓库内原始数据回放、模拟触摸与临时目录，覆盖单点连续运行、寿命测量抢占及恢复、等待旧线程退出、取消和故障停止、三点数据持久显示、SOH记录过滤及原始文件保留。此次GitHub同步不更新开发板；记录页筛选版按用户要求等待后续上板。

仓库根目录执行 `python -B -m unittest discover -s src/battery_eis/tests`，145项测试全部通过。新增测试使用仓库相对路径，未依赖工作电脑的盘符路径。
