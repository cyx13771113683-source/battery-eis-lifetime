# 锂电池 EIS 与寿命评估设计

## 应用与结构

面向锂电池状态检测，以电压、电流复幅值构建阻抗特征，再由轻量模型给出健康度相关输出。专用前端采用单极方波负载；电压为 AD0−AD1，电流为 (AD2−AD3)/R2，放电为正，复阻抗 Z=−Vac/Iac。

```text
锂电池四端接线 → 专用负载/电流参考 → ADS1256
                  ↑ DAC8552              ↓
             PL 保护控制 ← 时间戳/双通道锁相矩累积
                                         ↓ AXI
                     PS 校准/复阻抗/模型 → 三页触摸界面/记录
```

## 软硬件划分

PL 完成 SPI、真实 DRDY 时间戳、18 项矩累积、16384 条 RAM 与故障保护。PS 完成按实际时间戳拟合、复数传递校准、阻抗重建、记录导出、Ridge/森林推理及输入域核对。模型推理位于 PS。

## 频率、资源与优化

默认双频 2.16/17.8 Hz，各重复两次。BE03 将原始缓存从 4096 条扩为 16384 条，支持最长 4 秒单窗，低频采样避免旧缓存限制。实际 DDS 频率约 2.1653/17.8115 Hz；窗口安排预算为 11.21283996 秒，整次软件预算为 20 秒。整机耗时以实际测量记录为准。

BE03 冻结构建的 setup slack 为 +0.227 ns、hold slack 为 +0.018 ns；完整利用率、时钟、DRC 与时序数据见 `build/reports/`。软件及 FPGA 验证的来源、日期和实物结论见 `validation.md`。

## 模型与复现

保留冻结的 LIB Ridge 和 KIT 32 树森林及公开样例。输入需满足频率、温度、SOC、化学体系和校准域；不完整会话、非正常接法或域外输入会拒判。`model_bridge.py` 当前只接收显式冻结的研究模型；RUL 接口为 null。实物验证结论按负责人确认记录。

复现入口见仓库 README。装配依据为 `src/battery_eis/docs/final_assembly_log_20261021.md`，本次最终装配 R1=10Ω、R2=0.100Ω、R5=2.49kΩ；名义电压还原系数1.249，实际复数校准配置由使用者提供。
