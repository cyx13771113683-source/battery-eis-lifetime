# 电池阻抗前端最终装配日志：10Ω / 5W + 0.1Ω取样

确认日期：2026-10-21（北京时间）。适用板：Battery_EIS_REV_A，70 × 50 mm、双层 PCB。

用户最终确认：“就这个方案，需要换的电阻哪几个，有没有和别的一样的电阻可以不买新的，用多的”，随后要求“这个版本记录最终日志”。

**当前装配决定：沿用现有 PCB 的电气连接，不增加外部交流放大模块；R1 装 10Ω / 5W，R2 装 0.1Ω，R5 装 2.49kΩ。** 本日志取代同日较早的 68Ω / 1W 装配决定及讨论中的 33Ω / 1Ω候选。后续装配、软件参数和校准以本日志为准。

## 2. 安装与电流条件

- 原R1两孔中心距为20mm，孔径1.3mm，原预留本体约16 × 6mm。**5W标称不能证明本体适配；需按卖家尺寸核对。** 体积超出时，用短的绝缘引线连接原R1两孔，把功率电阻可靠固定在板旁通风处，远离电池、R2及采样线；不可由小焊盘承受悬空电阻的机械拉力。
- R2、R5沿用0402焊盘。R2保留靠近原电流取样位置的短连接，不改用长飞线取样。
- 电池端电压上限仍为5V。下表给出各电压的名义导通电流，被测电池必须允许对应的脉冲放电电流；不能仅凭外形为18650、AA或AAA就确认允许电流。
- 用户说明环境温度不超过20℃，风扇为可选散热措施。额定5W仍以具体厂家温度、安装和降额规定为准；不因低温或加风扇而自行提高额定功率。
- 本板依然没有独立的硬件欠压截止；首次连接前应先给ADDA上电并使DA0=0，测量过程中按电池化学体系设置欠压停止，断电前先停止放电并断开电池。

## 3. 接法与软件参数

受控放电支路：电池正极F+ → R1 → Q1漏极/源极 → R2 → F− → 电池负极。S+、S−分别独立接触电池正、负极，保留四线开尔文取样。

| 接口 | 作用 |
| --- | --- |
| J1从原图第1至4脚 | F+、S+、S−、F− |
| J2从原图第1至6脚 | AD0、AD1、AD2、AD3、DA0、AGND |
| AD0−AD1 | 经R5/R6分压后的电池电压 |
| AD2−AD3 | 经R7/R8及C2输入滤波后的R2压降，用于测电流 |
| DA0 | 控制MOS开关；本日志信号和功耗估算采用0/5V、50%占空比 |
| DA1 | 不使用 |

AD1、S−、AGND按原图连接；AD3对应的电流返回侧不能另行短接到AGND。J1一次连接一颗电池，可换接圆柱电池夹具或异形电池的四线开尔文夹；未使用的备用线束不接入即可。

目标ADDA为此前讨论的ADS1256 ADC + DAC8552 DAC模块。ADC四个输入脚组成**两组差分测量**，不是四个同时采样的ADC。ADS1256为复用采样，需要保留各路有效采样时刻并校准相位。

必须同步的软件名义参数：

- 取样电阻：`Rshunt_nominal = 0.100 Ω`，不是原10Ω，也不是中间候选1Ω。
- 分压比例：`kV_nominal = 10000 / (2490 + 10000) = 0.8006405124`。
- 电池电压名义还原系数：`1 / kV_nominal = 1.249`，不是原2。
- ADC：PGA=1、输入缓冲关闭；以下噪声对照采用VREF=2.5V。5V电池名义分压输出约4.0032V，不适合在AVDD=5V时打开ADS1256输入缓冲。
- 名义电流：`I = (V_AD2 - V_AD3) / Rshunt_actual`，V_AD2−V_AD3应先按实际通道增益与频响校正。不要把DAC命令值当作实测电流。
- 放电电流取正时，交流复阻抗按 `Z = -V_battery_ac / I_discharge_ac` 计算；电压、电流都使用同一频点的校准后复幅值，不能把幅值相减替代复数计算。

**100Hz是本次估算及初步验证的频率，不代表程序已配置为该值，也不代表已经验证了整个扫频范围。** ADC数据率3750SPS只是本日志噪声对照条件，不能把100Hz激励误当作ADC应设100SPS。相位校正须计入复用采样时间差与两个通道的模拟/数字滤波响应。

## 4. 电流与电阻功耗估算

以下是计算值而非实测。假设MOS导通电阻0.035Ω、电池内阻15mΩ，忽略线材和接触电阻，取名义R1=10Ω、R2=0.1Ω：

`I_on = E / (10 + 0.1 + 0.035 + 0.015)`；`P_R1,on = I_on² × 10`；`P_R2,on = I_on² × 0.1`。

| 电池电压 | 导通电流 | R1持续导通功耗 | R2持续导通功耗 | R1在50%占空比下平均功耗 |
| --- | --- | --- | --- | --- |
| 3.7V | 364.532mA | 1.32884W | 0.013288W | 0.66442W |
| 4.2V | 413.793mA | 1.71225W | 0.017122W | 0.85612W |
| 5.0V | 492.611mA | 2.42665W | 0.024267W | 1.21333W |

在5V上限，取R1低至9.5Ω（−5%）、R2为0.099～0.101Ω（±1%），并忽略其他正串联电阻分别求保守边界：导通电流约不超过0.521A，R1持续功耗约不超过2.578W，R2约不超过0.02740W。上述边界不表示实际温升或测量精度已验收；额定值仍需按具体元件与安装环境降额。

## 5. 内阻增加1mΩ的电压变化

以电池内阻从15mΩ变为16mΩ为例，考虑电流随总电阻变化；计算条件为100Hz、50%占空比单极放电脉冲。简化电池为理想电压源加电阻，本表不是任意电化学模型的完整EIS响应。

设 `Rext = R1 + R2 + Rmos = 10.135Ω`：

`ΔV_batt_step = E × [0.016/(Rext+0.016) - 0.015/(Rext+0.015)]`。

`ΔV_ADC_step = kV_nominal × ΔV_batt_step`；基波峰值变化 `ΔV_ADC_peak = (2/π) × ΔV_ADC_step`；基波RMS为峰值除以√2。

| 电池电压 | 电池端阶跃幅度增加 | ADC端阶跃幅度增加 | ADC端100Hz基波峰值增加 | ADC端基波RMS增加 |
| --- | --- | --- | --- | --- |
| 3.7V | 363.957µV | 291.399µV | 185.510µV | 131.176µV |
| 4.2V | 413.141µV | 330.777µV | 210.579µV | 148.902µV |
| 5.0V | 491.834µV | 393.783µV | 250.690µV | 177.264µV |

以上忽略实际电阻容差、ADC输入负载、模拟与数字滤波响应和接线寄生。不能将表中小数位数解释为测量准确度。3.7V时，本方案的1mΩ增量信号约为原100Ω/10Ω/1:2分压方案的17.34倍，为33Ω/1Ω/新分压候选的3.35倍。

## 6. ADC码宽、噪声与整机准确度的区别

TI ADS1256手册的典型噪声条件：25℃、AVDD=5V、VREF=2.5V、输入外部短接；此处取PGA=1、buffer关闭、DRATE=3750SPS。

| 指标 | ADC输入端电压 | 解释 |
| --- | --- | --- |
| 24位理论码宽 | 10V / 2²⁴ ≈ 0.596µV/码 | 数字量化步长，不是测量精度 |
| 典型输入等效噪声 | 5.413µV RMS | 芯片短接输入的典型噪声，不是模块±误差保证 |
| 典型无噪声分辨率 | 18.1位，对应约35.6µV峰峰值噪声量级 | 非严格的噪声上限 |
| 整块模块+PCB实际准确度 | 尚未确定 | 需要实物校准、重复性与独立标准件验证 |

3.7V时1mΩ变化产生约131.176µV RMS的基波变化，约为5.413µV RMS典型噪声的24.23倍。这个量级比较支持“先不加外部放大器进行直接采集验证”，但不证明整机已经稳定分辨1mΩ，更不证明绝对误差小于1mΩ。锁相积分可以降低部分随机噪声，不能自动消除同频串扰、增益/相位误差、温漂或接触变化。

## 7. 初始化与校准要求

1. 断电核对R1/R2/R5装配值、极性及四线接法；先给ADDA上电、DA0置0，再接电池并检查直流电压与欠压阈值。
2. 设置ADC的PGA、buffer和数据率后进行ADC自校准并等待完成。自校准不能替代外部电路和夹具校准。
3. 确认R2实际取样系数、R5/R6有效分压系数，以及ADC输入负载的影响；更换这些元件后重新做各使用频点的幅值/相位校准。
4. 电压、电流用同一频点的复幅值计算阻抗；R2始终在电流回路中，外接低阻标准件只用于校准/验证。
5. 外接无源标准电阻不能直接替代电池接J1而期望本板自行激励。此前讨论的验证方式为：电池供能、标准件串联在正极放电路径，通过改变S+取样位置进行加入标准件前后的比较；移动接线前先DA0置0。禁止把毫欧标准件直接跨接电池正负极。
6. 冻结校准后，用新数据验证已知小阻抗增量、重复夹取、温度及SOC变化的影响。“分辨1mΩ变化”“绝对误差小于1mΩ”“AI寿命估计准确”是三个不同的验收目标，均未由本日志证明。
